# Стандарты оформления

Стандарт — файл YAML: страница, корпоративный набор стилей и нумерация. У каждого
значения есть основание. Из файла `system_core/docx_standard_build.py` собирает:

- шаблон Word `.dotx`: из него создают новые документы;
- образец `.docx`: все стили в деле;
- описание для согласования: таблица стилей с колонкой «Поправка».

Правки коллег вносятся в файл стандарта, собранные документы руками не правятся.

| Файл | Стандарт | Шаблон |
|---|---|---|
| `notes.yaml` | Записки | `Записка.dotx` |
| `nir_gost_7_32.yaml` | Отчёт о НИР по ГОСТ 7.32-2017 | `Отчёт о НИР (ГОСТ 7.32).dotx` |

Сборка в `docs/standards`:

```
runtime\python.exe system_core\docx_standard_build.py --standard config\standards\notes.yaml --standard config\standards\nir_gost_7_32.yaml --outdir docs\standards --description "docs\standards\Стили документов - на согласование.docx"
```

## Основания

Значение пишется с основанием через `@`: `size: 12 @gost 6.1.1`. Без `@` действует
`basis` стиля или страницы.

| Основание | Что значит | В описании |
|---|---|---|
| `standard` | утверждённое значение; название — `standard_basis` файла | «Стандарт записок» |
| `gost 6.2.3, 6.4.1` | пункты ГОСТ; название — `gost_name` файла | «ГОСТ 7.32, пп. 6.2.3, 6.4.1» |
| `proposal` | предложение до уточнения | «Предложение», жёлтым |

Существующие документы источником значений не служат: они и есть то, что форматируется.

## Страница

```yaml
page:
  basis: proposal
  size: A4 @standard            # пока только A4
  margins_mm: 20 20 20 15       # верх низ лево право
  header_mm: 12.5               # колонтитулы от края листа
  footer_mm: 12.5
  page_number: right            # left, center, right - внизу
  first_page_number: no         # номер на первом листе
  rules:
    - 'Лист A3 | продолжает A4 вправо | standard'
```

`rules` — строки описания, которые не превращаются в свойства Word:
`'параметр | значение | основание'`.

## Стиль

```yaml
- name: Заголовок 1             # имя, как в Word на русском
  type: paragraph               # paragraph, character, table; по умолчанию paragraph
  role: 'раздел'                # для чего стиль
  based_on: Обычный
  next: Абзац                   # стиль абзаца после Enter
  basis: gost 6.2.3
  note: 'пояснение под заголовком стиля в описании'
  size: 14 @proposal
  bold: yes
  numbering: headings 1         # список из раздела numbering и уровень
  rules:
    - 'Текст | с прописной буквы, без точки в конце | gost 6.2.3'
```

Встроенные стили Word (`Обычный`, `Заголовок 1`–`9`, `Оглавление 1`–`9`,
`Название объекта`, `Абзац списка`, `Маркированный список`, `Нумерованный список`,
`Список литературы`, колонтитулы, сноски, `Гиперссылка`, `Номер страницы`,
`Сетка таблицы`) записываются под английскими именами Word, иначе Word заведёт второй,
пользовательский стиль с тем же названием. Остальные имена — пользовательские стили.

| Параметр | Значение |
|---|---|
| `font`, `size` | шрифт, кегль в пунктах |
| `bold`, `italic`, `caps`, `underline` | `yes` или `no` |
| `color` | `auto` или цвет `0000FF` |
| `vert_align` | `superscript` или `subscript` |
| `align` | `left`, `center`, `right`, `both` |
| `first_line`, `left` | отступы в сантиметрах; отрицательный `first_line` — выступ |
| `line` | межстрочный интервал множителем: `1`, `1.5` |
| `before`, `after` | интервалы в пунктах |
| `tabs` | `center 8.25; right 16.5 dot` — позиции в сантиметрах, `dot` — отточие |
| `numbering` | `<список> <уровень>` |
| `keep_next`, `keep_lines`, `page_break_before` | `yes` или `no` |
| `no_hyphenation` | `yes` — переносы запрещены |
| `outline` | уровень заголовка для оглавления, 1–9 |
| `borders` | у таблицы: `single 0.5` — одинарные линии толщиной в пунктах |

## Нумерация

```yaml
numbering:
  headings:                     # многоуровневый список для заголовков
    - {format: decimal, text: '%1'}
    - {format: decimal, text: '%1.%2'}
  bullet:
    - {format: bullet, text: '–'}
  lettered:
    - {format: russianLower, text: '%1)'}
```

Отступ номера берётся у стиля, который ссылается на уровень; после номера — пробел.

## Набор стилей

В корпоративном оформлении 20–40 стилей, остальное — мусор. В шаблон попадают стили
файла и три служебных стиля Word по умолчанию: «Основной шрифт абзаца», «Обычная
таблица», «Нет списка». Прочие встроенные стили Word скрыты из коллекции стилей.
